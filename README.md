# UPSC ZONE AI — Competition Landing Page V2

A responsive, competition-ready landing page prototype for an AI-powered UPSC preparation platform.

## V2 polish
- Preserves the original visual design and responsive layout.
- Dashboard date is generated from the visitor's local date, so the weekday cannot become stale.
- Prototype metrics and current-affairs content are explicitly labeled as demo/sample content.
- Added a custom UPSC ZONE AI favicon.
- Added an interactive preparation-goal onboarding modal to the main Start Preparing CTAs.
- Added accessibility improvements: dialog semantics, labels, keyboard Escape support, focus-visible states and disabled-state handling.
- No backend or real authentication is included; login/onboarding are UI prototype flows.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling and animations
- `script.js` — interactions, animations and prototype flows
- `favicon.svg` — browser tab icon

## Run locally
Open `index.html` with VS Code Live Server.

## Deploy
Upload the contents of this folder to a static host such as Netlify. `index.html` must remain at the project root.
